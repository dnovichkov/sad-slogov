# Сад слогов

Тренажёр чтения по слогам для совместных занятий ребёнка и взрослого. Дополняет занятия по «Букварю» Жуковой: закрепляет то, что уже пройдено в книге. Задания и слова произносит взрослый, ребёнок нажимает на большие кнопки.

Статический сайт на HTML, CSS и JavaScript без зависимостей. Иллюстрации встроены в код как SVG. Сервер приложения, база данных и API-ключи не нужны.

## Учебный материал

Буквы идут в порядке «Букваря» Жуковой:

> А, У, О, **М**, **С**, **Х**, **Р**, **Ш**, Ы, Л, Н, К, Т, И, П, З, Й, Г, В, Д, Б, Ж, Е, Ь, Я, Ю, Ё, Ч, Э, Ц, Ф, Щ, Ъ

Сейчас в тренажёре пять согласных и четыре гласные — 18 слогов и 34 слова:

| Буква | Слоги |
| --- | --- |
| М | МА МУ МО МЫ |
| С | СА СУ СО СЫ |
| Х | ХА ХУ ХО |
| Р | РА РУ РО РЫ |
| Ш | ША ШУ ШО |

Слогов ХЫ и ШЫ нет намеренно: в русском языке они не встречаются. У буквы Ш вместо ШЫ позже появится ШИ, вместе с гласной И.

По умолчанию включены М и С — материал до страницы 16 букваря. Остальные буквы взрослый добавляет в настройках, когда ребёнок до них дойдёт.

### Три игры

- **Карточки слогов** — ребёнок читает слог вслух, взрослый отмечает результат.
- **Подружи буквы** — выбрать согласную, затем гласную и прочитать, как звуки слились.
- **Где спрятался слог?** — по картинке или написанному слову найти знакомый слог. Слог может стоять в начале, в середине или в конце: МУХА, БУСЫ, МЕШОК. В настройках есть лёгкий режим «только в начале».

## Запуск

Нужен Node.js 18 или новее. Внешних зависимостей нет, `npm install` не требуется.

```sh
npm run dev
```

Откройте <http://127.0.0.1:3000>. После правок обновляйте страницу браузера.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер для `public/` |
| `npm run check` | Согласованность учебного материала и синтаксис скриптов |
| `npm test` | Прогон занятия целиком: инварианты заданий, история, настройки |
| `npm run build` | Проверка, тест и сборка в `dist/` |
| `npm run preview` | Локальный сервер для собранного `dist/` |

Другой порт: `npm run dev -- --port 3001`. Проверка с телефона в той же сети: `npm run dev -- --host 0.0.0.0`, затем откройте `http://IP-АДРЕС-КОМПЬЮТЕРА:3000` (компьютер должен разрешать входящие подключения к этому порту).

## Как добавить следующую букву

Следующая по букварю — **Ы** как отдельная страница, затем Л, Н, К, Т и гласная И.

1. **Буква.** Допишите её в `LETTERS` в `public/curriculum.js` — после предыдущей, порядок списка задаёт порядок в настройках.

   ```js
   {
     id: "Л",
     vowels: ["А", "У", "О", "Ы"],   // только существующие слияния
     sound: "л-л-л",                 // как взрослому тянуть звук
     tip: "Кончик языка за верхними зубами...",
     note: "…",                      // необязательно: орфографическая ремарка
   }
   ```

2. **Слова.** Добавьте в `WORDS` по два слова на слог — ребёнку нужны разные задания на один слог.

   ```js
   { word: "ЛУНА", spoken: "луна́", art: "moon", teaches: ["ЛУ"] }
   ```

   - `spoken` — то же слово строчными буквами с одним знаком ударения.
   - `teaches` — слоги, которым слово учит. Сюда попадает только то, что **отчётливо слышно**, когда взрослый произносит слово по слогам. Безударная «О» звучит как [а]: «соро́ка» это [сарока], поэтому СОРОКА учит РО, но не СО. Если безударная «О» всё-таки нужна, добавьте `unstressed: ["ХО"]` — это осознанное решение, и проверка о нём спросит.
   - Список `contains` считается сам: это все слоги курса, встречающиеся в слове. Он вычитается из неверных вариантов ответа, чтобы в слове МУХА не предложили одновременно МУ и ХА.

3. **Рисунок.** Положите SVG в `WORD_ART` в `public/art.js` под тем же ключом, что в поле `art`. Правила: viewBox `0 0 240 170`, предмет примерно в области x 40..200 и y 30..150, цвета из `PALETTE`, плоские заливки без градиентов и фильтров.

4. **Проверьте.**

   ```sh
   npm run check   # слоги без слов, опечатки в ключах, ударения, целостность SVG
   npm test        # инварианты заданий
   npm run dev     # и откройте /art-sheet.html — все рисунки на одном листе
   ```

Трогать `app.js` при этом не нужно: интерфейс, подсказки и варианты ответа строятся из данных.

## Поведение и данные

- Серии на 3, 6 или 9 заданий; по умолчанию 6. Смешанная серия и три отдельные игры.
- Чтение вслух отмечает взрослый; выбор букв и слогов проверяет интерфейс.
- Подсказки, повторы, пауза, завершение неполной серии.
- Настройки и до 20 результатов хранятся в localStorage под ключом `sad-slogov-v2`; в режиме взрослого видны последние 5 занятий. Сохранения версии 1 переносятся автоматически.
- При запрете localStorage игра работает до закрытия страницы без сохранения результатов.
- Текущее незавершённое задание при перезагрузке сбрасывается.
- История отдельная в каждом браузере и привязана к origin: при смене домена не переносится.

## Размещение

Ветка `main` публикуется на GitHub Pages через `.github/workflows/pages.yml`. Включите Pages в настройках репозитория с источником **GitHub Actions**. Про другие варианты — [DEPLOY.md](DEPLOY.md).

Встроенной авторизации нет: на публичном хостинге сайт доступен всем, кто знает адрес. `noindex,nofollow` в HTML — просьба к поисковикам не индексировать страницу, а не ограничение доступа. Для семейного доступа настройте ограничение средствами хостинга.

Страницы и иллюстрации «Букваря» Жуковой в проект не включены: это самостоятельные упражнения для закрепления пройденного.
