# Сад слогов — исходники

Тренажёр для совместных занятий ребёнка и взрослого: карточки, соединение букв и поиск начала слова по картинке или написанному слову. Учебный материал — **СА, СУ, СО**. Задания и слова произносит взрослый.

Самостоятельный статический сайт на HTML, CSS и JavaScript, со встроенными SVG-иллюстрациями. Сервер приложения, база данных, API-ключи и доступ к ChatGPT экспортированной версии не нужны.

## Локальный запуск

Распакуйте архив и откройте терминал в папке `sad-slogov`.

Нужен Node.js. Экспорт проверен на Node.js v24.19.0. Внешних npm-зависимостей нет; `npm install` не требуется.

```sh
npm run dev
```

Откройте <http://127.0.0.1:3000>. После правок обновляйте страницу браузера.

Другой порт:

```sh
npm run dev -- --port 3001
```

Для проверки с телефона в той же локальной сети:

```sh
npm run dev -- --host 0.0.0.0
```

Откройте на телефоне `http://IP-АДРЕС-КОМПЬЮТЕРА:3000`. Компьютер должен разрешать входящие подключения к этому порту.

## Сборка

В архиве уже есть готовая папка `dist/`. После изменения исходников пересоберите её:

```sh
npm run build
```

Локальная проверка сборки:

```sh
npm run preview -- --port 3001
```

Откройте <http://127.0.0.1:3001>. Для размещения на внешнем сервере используйте содержимое `dist/`; подробности — в [DEPLOY.md](DEPLOY.md).

## Где что менять

| Файл | Назначение |
| --- | --- |
| `public/app.js` | Игровая логика, задания, настройки, история, SVG-иллюстрации |
| `public/style.css` | Цвета, размеры, отступы, мобильная вёрстка |
| `public/index.html` | Заголовок страницы, шапка, подвал и каркас диалогов |
| `public/icon.svg` | Значок вкладки |
| `build.mjs` | Копирование проверенных файлов из `public/` в `dist/` |
| `dev-server.mjs` | Локальная раздача исходников и сборки |
| `package.json` | Команды `dev`, `build`, `preview` |
| `QA.md` | Проверки исходной версии |
| `EXPORT-QA.md` | Проверки экспортированной версии |

Редактируйте файлы в `public/`: `dist/` полностью пересоздаётся при сборке.

В начале `public/app.js` находятся `SYLLABLES` (слоги), `WORDS` (слова и картинки), `initial` (настройки по умолчанию), `STORE` (ключ localStorage). Функции `renderHome`, `renderLesson`, `showAdult` формируют главную страницу, задания и режим взрослого. `wordArt` и `gardenArt` рисуют иллюстрации.

Добавление других согласных требует обновить упражнения и подсказки: соединение букв рассчитано на «С», поэтому одного изменения `SYLLABLES` недостаточно. Учебный материал также указан в текстах главной страницы и настроек.

## Поведение и данные

- Серии на 3, 6 или 9 заданий; по умолчанию 6. Смешанная серия и три отдельные игры.
- Чтение вслух отмечает взрослый; выбор букв и слогов проверяет интерфейс.
- Подсказки, повторы, пауза, завершение неполной серии.
- Настройки и до 20 результатов хранятся в localStorage; в режиме взрослого видны последние 5 занятий.
- При запрете localStorage игра работает до закрытия страницы без сохранения результатов.
- Текущее незавершённое задание при перезагрузке сбрасывается.
- История отдельная в каждом браузере. При смене домена автоматически не переносится: данные привязаны к origin (протокол, домен, порт).

## Приватный доступ

Приватность исходного сайта обеспечивает платформа ChatGPT. **В архиве нет авторизации.** На обычном публичном хостинге сайт будет доступен его посетителям. Ограничение доступа для семьи можно настроить средствами хостинга или добавить самостоятельно.

В экспортированной версии метка «Приватное занятие» заменена на «Читаем вместе». В HTML сохранено `noindex,nofollow`: это просьба к поисковикам не индексировать страницу, а не защита от доступа.

Страницы и иллюстрации «Букваря» Жуковой в проект не включены.
