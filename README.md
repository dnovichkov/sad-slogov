# Сад слогов

**Открыть: <https://sad-slogov.dmdp.ru/>**

Тренажёр чтения по слогам для совместных занятий ребёнка и взрослого. Дополняет занятия по «Букварю» Жуковой: закрепляет то, что уже пройдено в книге. Задания и слова произносит взрослый, ребёнок нажимает на большие кнопки.

Статический сайт на HTML, CSS и JavaScript без зависимостей. Иллюстрации встроены в код как SVG. Сервер приложения, база данных и API-ключи не нужны.

## Учебный материал

Весь букварь: **33 буквы, 147 прямых слогов, 126 обратных, 198 слов, 125 иллюстраций, 78 предложений и коротких текстов.**

Порядок букв — как в книге:

> А, У, О, М, С, Х, Р, Ш, Ы, Л, Н, К, Т, И, П, З, Й, Г, В, Д, Б, Ж, Е, Ь, Я, Ю, Ё, Ч, Э, Ц, Ф, Щ, Ъ

### Материал задаётся двумя осями, а не одной

Слог появляется, когда пройдены **обе** его буквы. «М» знают с 12-й страницы, но МЫ читают только после страницы с «Ы», МИ — после «И», МЯ — после «Я». Поэтому в настройках согласные и гласные отмечаются отдельно, а кнопка «мы дошли до буквы X» режет общий список алфавита, где гласные и согласные чередуются.

| Дошли до буквы | Гласные | Слогов | Со словом | С рисунком | Слов для чтения | Предложений |
| --- | --- | --- | --- | --- | --- | --- |
| С | А У О | 6 | 6 | 6 | 3 | 0 |
| Т | + Ы | 33 | 33 | 32 | 27 | 14 |
| И | + И | 42 | 42 | 41 | 37 | 20 |
| Ж | | 75 | 73 | 61 | 93 | 45 |
| Ь | + Е | 91 | 86 | 69 | 129 | 53 |
| Ё | + Я Ю Ё | 126 | 107 | 80 | 158 | 61 |
| Ъ | + Э | 147 | 124 | 89 | 198 | 78 |

По умолчанию отмечены М, С и гласные А, У, О — материал до страницы 16 включительно.

### Слияния, которых нет

Решётка «согласная × гласная» неполная, и это не упрощение, а орфография. В данных у каждой буквы свой список гласных, а проверка следит, чтобы в тренажёр не попало:

- **ЖЫ, ШЫ** — пишется ЖИ, ШИ;
- **ЧЯ, ЧЮ, ЩЯ, ЩЮ** — пишется ЧА, ЧУ, ЩА, ЩУ;
- **ЦЯ, ЦЮ, ЦЁ** — Ц всегда твёрдый;
- **ГЫ, КЫ, ХЫ** — заднеязычные с Ы не сочетаются;
- **Э после согласной** — только в заимствованиях (мэр, сэр), в слияния не берём.

**Й, Ь и Ъ** слогов не дают вовсе. Й замыкает слог (МАЙ-КА, ЧАЙ), Ь смягчает, Ъ разделяет — все трое участвуют в игре «Прочитай слово».

23 слияния остались без слова: МЮ, СЮ, ХЕ, РЯ, НЮ, ПЮ, ЗЮ, ЗЁ, ГЕ, ВУ, ВЮ, ВЁ, ДЮ, ДЁ, БЯ, БЮ, БЁ, ЖО, ЖЕ, ЧЕ, ЧЁ, ЦУ, ЩЕ. Частого детского слова на них в русском языке нет. Они читаются в карточках и в соединении букв, но в поиске слога не встречаются.

## Семь игр

| Игра | Что делает ребёнок | Когда доступна |
| --- | --- | --- |
| **Карточки слогов** | Читает слог вслух, взрослый отмечает результат | всегда |
| **Подружи буквы** | Выбирает согласную, затем гласную, читает слияние | всегда |
| **Обратный слог** | Читает АМ, ОХ, УС — гласная впереди | всегда |
| **Где спрятался слог?** | По картинке или слову находит знакомый слог | есть слово на этот слог |
| **Прочитай слово** | Читает целое слово по слогам | есть слово из пройденных букв |
| **Прочитай предложение** | Читает предложение или короткий текст | есть запись из пройденных букв |
| **Твёрдый или мягкий?** | На слух различает МА и МЯ, ЛУ и ЛЮ, СЫ и СИ | выбраны и твёрдые, и мягкие гласные |

Недоступная игра просто не показывается. В чтение попадают только слова и предложения, целиком составленные из пройденных букв: ребёнок не упирается в незнакомую букву.

### Что повторяется чаще

Приложение запоминает по каждому слогу, сколько раз он встретился и сколько раз понадобилась помощь, и смещает выбор заданий к трудному. Вес: 1 — всегда читался сам, 4 — всегда с помощью, 1.4 — ещё не встречался. Это смещение, а не фильтр: лёгкие слоги продолжают выпадать, новый материал не вытесняется. Счёт общий для всех игр со слогами и виден взрослому в настройках.

## Запуск

Нужен Node.js 18 или новее. Внешних зависимостей нет, `npm install` не требуется.

```sh
npm run dev
```

Откройте <http://127.0.0.1:3000>. После правок обновляйте страницу браузера.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер для `public/` |
| `npm run check` | Согласованность учебного материала и синтаксис скриптов |
| `npm test` | Прогон занятия целиком: инварианты заданий, история, настройки |
| `npm run build` | Проверка, тест и сборка в `dist/` |
| `npm run preview` | Локальный сервер для собранного `dist/` |
| `npm run shots` | Снимки экранов в `screenshots/` через Chrome без окна |

Другой порт: `npm run dev -- --port 3001`. Проверка с телефона в той же сети: `npm run dev -- --host 0.0.0.0`, затем откройте `http://IP-АДРЕС-КОМПЬЮТЕРА:3000` (компьютер должен разрешать входящие подключения к этому порту).

## Как добавить слово

В `WORDS` в `public/curriculum.js`:

```js
["ЛУ-НА", "луна́", "moon"],
```

1. **Слово по слогам.** Дефисы задают и разбивку для игры «Прочитай слово», и обычное написание.
2. **Произношение** — то же слово строчными буквами с одним знаком ударения. Слова с «ё» пишутся без знака: в русском языке она всегда ударная.
3. **Ключ рисунка** — необязателен. Слово без рисунка работает в обеих играх, просто показывается текстом.
4. **Четвёртое поле** — возврат безударного слога, см. ниже.

Каким слогам учит слово, считается автоматически: берутся все слияния курса, которые есть в слове. Исключение — безударные **О, Е, Я**: они звучат как [а] и [и], ребёнок их не услышит. «соро́ка» это [сарока], поэтому СОРОКА учит РО, но не СО. Если слово всё-таки нужно на такой слог, добавьте его четвёртым полем — проверка примет это как осознанное решение:

```js
["ХО-МЯК", "хомя́к", "hamster", ["ХО"]],
```

Отдельно считается список всех слогов, которые в слове есть. Он вычитается из неверных вариантов ответа: в слове МУХА спрятаны и МУ, и ХА, и ребёнок был бы прав, указав любой.

### Как добавить предложение

В `TEXTS` в том же файле. Слова разделены пробелами, слоги внутри слова — дефисами, знаки препинания пишутся слитно со словом:

```js
"МА-МА МЫ-ЛА РА-МУ.",
"ТУТ НО-РА. ТАМ КРОТ. КРОТ У-СНУЛ.",
```

Несколько предложений подряд — это короткий текст, он покажется отдельными строками. Разбор считается сам. Занятие берёт только записи, где нет ни одной непройденной буквы, поэтому длинные тексты появляются позже сами собой — порядок в списке ни на что не влияет, но по нему удобнее ориентироваться.

### Как добавить рисунок

Положите SVG в `WORD_ART` в `public/art.js` под тем же ключом, что в поле `art`. Правила: viewBox `0 0 240 170`, предмет примерно в области x 40..200 и y 30..150, цвета из `PALETTE`, плоские заливки без градиентов и фильтров.

### Как добавить букву

Букварь закончен, но если нужно: допишите букву в `ALPHABET` на её место в порядке, укажите `kind`, а для согласной — список существующих слияний (`vowels`), `sound`, `hold` (можно ли тянуть звук) и `tip`. Интерфейс, подсказки и варианты ответа строятся из данных — `app.js` трогать не нужно.

### Проверьте

```sh
npm run check   # слоги, ударения, ключи рисунков, целостность SVG
npm test        # инварианты заданий
npm run dev     # и откройте /art-sheet.html — все рисунки на одном листе
```

## Поведение и данные

- Серии на 3, 6 или 9 заданий; по умолчанию 6. Смешанная серия и шесть отдельных игр.
- Чтение вслух отмечает взрослый; выбор букв и слогов проверяет интерфейс.
- Подсказки, повторы, пауза, завершение неполной серии.
- Подсказка взрослому различает тянущиеся и взрывные звуки: К, Т, П, Г, Д, Б, Ц и Ч тянуть нельзя, слог произносится одним движением.
- Счёт по слогам и до 20 результатов хранятся вместе с настройками в localStorage под ключом `sad-slogov-v3`; «Очистить историю» убирает и то, и другое; в режиме взрослого видны последние 5 занятий. Сохранения версий 1 и 2 переносятся автоматически.
- При запрете localStorage игра работает до закрытия страницы без сохранения результатов.
- Текущее незавершённое задание при перезагрузке сбрасывается.
- История отдельная в каждом браузере и привязана к origin: при смене домена не переносится.

## Размещение

Push в `main` выкладывает сайт сразу в двух местах, вручную ничего делать не нужно:

| Адрес | Workflow | Как устроено |
| --- | --- | --- |
| <https://sad-slogov.dmdp.ru/> — основной | `.github/workflows/deploy.yml` | образ nginx собирается в GHCR и выкатывается на сервер; маршрут и карточка на <https://projects.dmdp.ru/> заданы в реестре `sites_configs` |
| <https://dnovichkov.github.io/sad-slogov/> — зеркало | `.github/workflows/pages.yml` | `dist/` выкладывается на GitHub Pages |

Оба пути запускают один и тот же `npm run build` (проверка материала, тест занятия, сборка). Про другие варианты размещения — [DEPLOY.md](DEPLOY.md).

История занятий привязана к адресу сайта: у тех, кто занимался на github.io, на новом домене она начнётся с нуля.

Встроенной авторизации нет: на публичном хостинге сайт доступен всем, кто знает адрес. `noindex,nofollow` в HTML — просьба к поисковикам не индексировать страницу, а не ограничение доступа. Для семейного доступа настройте ограничение средствами хостинга.

Страницы и иллюстрации «Букваря» Жуковой в проект не включены: это самостоятельные упражнения для закрепления пройденного.
