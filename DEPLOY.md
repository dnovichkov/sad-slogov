# Внешнее размещение

## Загрузка готовых файлов

1. При необходимости выполните `npm run build`.
2. Загрузите **содержимое** `dist/` в корень сайта: рядом должны оказаться `index.html`, `app.js`, `style.css`, `icon.svg`.
3. Откройте адрес сайта и начните занятие.

Node.js на хостинге не нужен. Можно разместить сайт в подпапке: пути к файлам относительные. Адрес подпапки должен оканчиваться `/`.

## Сборка из Git на хостинге

Создайте свой репозиторий из папки `sad-slogov` и подключите его к хостингу статических сайтов.

| Настройка | Значение |
| --- | --- |
| Тип проекта | Статический сайт / Other |
| Корневая папка | Папка с `package.json` |
| Команда сборки | `npm run build` |
| Папка публикации | `dist` |
| Установка зависимостей | Не требуется |
| Команда запуска сервера | Не требуется |
| Переменные окружения / API-ключи | Не требуются |

Если хостинг требует команду установки, `npm install` допустима: внешних зависимостей нет. `npm ci` требует lock-файл, которого в этой копии нет.

## Свой веб-сервер

Укажите в конфигурации веб-сервера корневой каталог с содержимым `dist/` и индексный файл `index.html`. Файлы должны отдаваться с обычными MIME-типами для HTML, JavaScript, CSS и SVG. Перенаправление клиентских маршрутов не требуется: приложение работает на одной странице.

Для внешнего адреса используйте HTTPS. Команды `dev` и `preview` предназначены для локальной проверки.

## Доступ и обновление

Встроенной авторизации и серверного хранения нет. Для приватного размещения настройте ограничение доступа средствами хостинга. `noindex` и скрытая ссылка не заменяют авторизацию. `private: true` в `package.json` запрещает случайную публикацию npm-пакета и не ограничивает доступ к сайту.

История и настройки хранятся у каждого посетителя в браузере. Новый домен означает отдельное хранилище.

При обновлении выкладывайте весь `dist/`: имена файлов не содержат хешей. Настройте повторную проверку кэша для HTML, JS и CSS или очистите кэш хостинга, чтобы посетители получили согласованную версию.

После публикации проверьте начало и завершение серии, подсказки, паузу, настройки взрослого, сохранение после перезагрузки и нажатия на телефоне.
