# Проверка экспортированной версии

- `npm run build` завершилась успешно на Node.js v24.19.0.
- Исходники и результат сборки прошли синтаксическую проверку JavaScript.
- Локальный сервер проверен отдельно с `public/` и `dist/`: HTML, JavaScript, CSS и SVG возвращают HTTP 200 и совпадают с файлами на диске. Документация из корня проекта не раздаётся.
- Игры в собранной версии повторно проверены в Chromium 149: настольный экран 1440×1000 и эмуляция сенсорных телефонов 390×844 и 320×740.
- Пройдены полная серия из шести заданий, ошибки и повторные попытки, соединение букв, подсказки, пауза, отчёт о занятии, выбор слогов, серия из трёх заданий, режим слов, сохранение и очистка истории, завершение неполной серии.
- Проверен режим с запрещённым localStorage.
- В проверенных сценариях нет ошибок JavaScript и горизонтального переполнения.
- Архив проверен на целостность; файлы в ZIP сверены с подготовленной копией.

Проверки телефона выполнены в эмуляции браузера; физические устройства и Safari отдельно не проверялись.
