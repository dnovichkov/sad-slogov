# О переносимой версии

Подготовлено 11 сентября 2026 года из опубликованной версии 1 проекта «Сад слогов». Исходный коммит: `a1f59b4aecd5b07bbda96e23d857fd1190aaf395`.

Изменения в экспортируемой копии:

- Исходники отформатированы для доработки.
- Метка «Приватное занятие» и значок замка заменены на «Читаем вместе» и значок книги: внешняя копия не содержит платформенной авторизации.
- Локальный сервер поддерживает `--dir public|dist` и `--host`; по умолчанию доступен на `127.0.0.1`.
- Добавлена команда `npm run preview`, инструкции и пересобранная папка `dist/`.

Игровая логика, задания и иллюстрации сохранены. В архив не включены привязка к исходному проекту Sites, история Git, токены, результаты занятий и временные файлы. Работающий приватный сайт не изменялся.
